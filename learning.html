Learning Resources

The following guidance can help users recognise common phishing techniques and reduce the risk of falling victim to online scams. While no single indicator guarantees that a message is malicious, reviewing these warning signs can help improve online safety.

📧 Check the sender address

Phishing emails often use addresses that look similar to legitimate organisations. Check carefully for unusual spelling, extra numbers, or unfamiliar domains before trusting the message.

⚠️ Be careful with urgent messages

Attackers often try to create panic by claiming that an account will be suspended, a payment is overdue, or immediate action is required. Taking a moment to verify the message can help prevent mistakes.

🔗 Do not trust links automatically

Links in phishing emails may lead to fake websites designed to steal information. If you are unsure, visit the organisation's official website directly rather than using the link provided in the message.

🔒 Watch for requests for personal information

Legitimate organisations rarely ask for passwords, banking information, or security codes through email. Unexpected requests for sensitive information should be treated with caution.

📝 Check for spelling and grammar mistakes

Many phishing emails contain spelling mistakes, unusual wording, or formatting issues. Although some attacks are well written, these signs can still indicate a fraudulent message.

📎 Be cautious with attachments

Unexpected attachments may contain malicious software or harmful files. Do not open attachments unless you are confident about the sender and the purpose of the message.

✔️ Verify suspicious messages

If you are unsure whether a message is genuine, contact the organisation using a trusted phone number or website. Avoid using contact details provided in the suspicious message.

🔄 Keep software updated

Regular software updates can help protect devices against security vulnerabilities that attackers may attempt to exploit.
